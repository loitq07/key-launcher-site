1. Home Screen & Keyboard Experience

dialpad

T9 Search & Accent Engine

Key Launcher features a custom 3x4 layout home keypad. Keystrokes match characters recursively to filter apps instantly.

Accent Matching Algorithm

You do not need to select accented characters manually. Key Launcher maps standard alphanumeric T9 keystrokes to diacritic characters automatically:

  • Type 6 → 6 → 4 → 2 (MNO → MNO → GHI → ABC) to filter "Nhạc".
  • Type 8 → 4 → 3 → 8 (TUV → GHI → DEF → TUV) to filter "Thiết".

The search result displays matching apps immediately above the keyboard layout, sorting by frequency of launches to ensure your most-used apps stay on top.

aspect_ratio

Keypad Layout & Sizing

Customize the keyboard structure and height to fit your device specifications and one-handed reach:

  • Key Layout Modes:
    • Auto: Dynamically sizes based on keyboard height.
    • Side by Side: Aligns numbers and letters horizontally inside the same button.
    • Stacked: Centers numbers on top and scales alphabetical letters underneath.
  • Height Calculations: Toggle "Automatically calculate keyboard height" or slide manually to set key sizes.
  • Bottom Spacing: Add additional padding at the bottom of the screen to push the keypad higher, perfect for tall bezel-less smartphones.
  • Sizing Metrics: Adjust key transparency (opacity sliders) and customize the visual font scale of text labels.
Settings Path: Swipe Up → Keyboard Configuration → Layout / Size sections.
palette

Visual Themes & Colors

Customize the visual style of your key surfaces and system accents:

  • Keyboard Surface Themes:
    • Minimalism: Modern visual look with transparent gradient glassmorphic button overlays.
    • Flat Skeumorphism: Retro bezel style showing a flat display border bezel look.
    • Curved Skeumorphism: Retro bezel style featuring simulated curved display bezel borders.
  • Minimal Dots Button Mode: Toggle to replace all numbers and letters on the keypad with flat clean dots. This blocks visual triggers and assists with mobile screen detox.
  • Color Palette Selectors: Set Key Color and Background Color modes:
    • White/Black: High contrast minimalist styling.
    • Accent Color: Syncs with system Material You wallpaper colors.
    • Custom: Launches hex selectors to color code individual surfaces.
volume_up

Audio Feedback Profiles

Key Launcher supports custom audio click feedback profiles to enhance typing tactile feel.

Go to settings to select from three preset sound waves (Sound 1, Sound 2, or Sound 3) and adjust the feedback volume slider from 0% to 100% output.

vpn_key

Super Shortcuts (Hotkeys)

Bind keypad keys 1-9 to trigger instant launches. By mapping shortcuts, you avoid typing search queries altogether.

Double Tap Key Double tap the key on the home keypad to open the assigned app or shortcut instantly.
Press & Hold (500ms) Long press the key to execute the associated action immediately.

Configurable Actions: Mappings are not limited to applications. You can bind system operations (e.g. Flashlight, Lock screen, Dialer, or App search drawers).

Free plan limits: Free accounts configure up to 3 shortcuts (keys 1-3). Upgrading to PRO unlocks all 9 key slots.
chat_bubble

Contacts & Chat Bridges

Locate people instantly. Type a phone number or contact name using T9 to show call shortcut cards.

  • Phone Number Queries: Typing a number matches local contacts and displays a dialer card. Tapping calls the number directly.
  • Messaging Bridges: Results contain quick action shortcuts. Clicking Zalo, Viber, or WhatsApp queries the phone number and launches the chat thread immediately inside those apps.
Privacy Architecture: Contacts querying is sandboxed and takes place 100% offline on your device database. Contact data is never uploaded.
security

Samsung Secure Folder

Manage locked containers. Key Launcher integrates with Samsung's Secure Folder environment.

Once enabled in Advanced Settings, sandboxed apps from the Secure Folder are listed inside search and grid views. Launching them invokes the official Samsung password/biometric challenge dialog.

2. App & Folder Management

grid_view

Pinned Grid & Shift Reordering

Customize your pinned grid at the top of the dialer for immediate access to main apps.

  • Shift Reorder: Long-press a pinned app to drag. Rather than swapping places, adjacent icons slide over sequentially to accommodate the new layout.
  • Hover-Merge: Drag a pinned icon and hold it over another icon for 1 second. Release to merge them into a Folder.
view_agenda

AllApps Folder Strip

Manage folders efficiently inside the app drawer:

  • Category Lock: The Folder Strip only displays when you view the **"All"** category in the app drawer.
  • Floating Overlays: Dragging any app from the drawer triggers a slide-down floating strip overlay.
  • Drag to Add/Create: Drop the app on an existing folder icon to add it, or drop it on the empty space on the strip to generate a new folder.
blur_on

Folder Overlay UI

Clicking a folder opens a full-screen blurred dialog containing the items.

App Hiding Rule: All apps nested in folders are hidden from the general AllApps list to reduce clutter, but they remain instantly matchable when searching T9.

Context Menu: Long-press an icon inside the blurred folder overlay and select "Remove from folder". If a folder contains 1 or 0 items, it automatically dissolves and return items to the general layout.

3. Universal Search Overlay

calculate

Decimal Calculator

The search bar doubles as a math evaluator. Type math expressions directly using the T9 keyboard.

Supported Ops: Addition, subtraction, multiplication, division, modulo, exponentiation, and nested brackets (+ - * / % ^ ( )).

The parsed output appears in a card on top with a "Copy" button to instantly paste results to your clipboard.

settings_accessibility

Settings Search Registry

Skip crawling system menu layouts. Search over **35 system settings shortcuts** directly.

Typing terms like "wifi", "battery", "bluetooth", or "display" instantly matches settings items. Tapping them executes system intents to open those panels immediately.

drafts

MediaStore Local Files

Query local files (images, audio, videos, documents) right from T9.

Lazy Permission Wall: The app does not request external storage access on startup. Instead, it asks for permission (`READ_MEDIA_*` or `READ_EXTERNAL_STORAGE`) lazily only when you search for files the first time.

Tapping file results fires an ACTION_VIEW intent with temporary read permissions to display the file in your preferred viewer.

open_in_new

Web & Play Store Shortcuts

If your query does not match local apps, dynamic web cards display at the bottom of the list.

  • Google Web Search: Launches your default browser directing to google.com/search?q=.
  • Play Store Search: Launches the Play Store application querying market://search?q=.

4. Interactive Edge Panels

layers

Edge Panel Back-Stack

Swipe horizontally from the home screens to reveal overlays. Key Launcher supports stacking up to **2 panels per edge** (Left and Right edges).

Layered Sliding: Swipe horizontal once to open the first panel (slot 0). Swipe horizontal again to slide the second panel (slot 1) over the first with a z-stack parallax offset (slot 0 remains visible underneath, translated 60dp and faded).

Retreating: Swipe back towards the edge or press the back button to close slot 1, sliding slot 0 back into focus.

Chain Constraint: NOTIFICATION_CENTER must always be placed as the LAST panel in a chain. Because notification items consume horizontal swipes for dismiss gestures, you cannot swipe forward out of it.
widgets

Widget Center (AQI)

Place your system widgets in one swipe-away hidden container. Keep your launcher looking clean.

In addition to standard widgets, the Widget Center shows a weather banner displaying Air Quality Index (AQI) data retrieved via OpenWeather and WAQI.

*Limits: Free accounts can add up to 3 widgets. PRO accounts get unlimited widgets and custom background wallpaper/overlay opacity controls.

notifications_active

Notification Center

Manage notifications on a dedicated screen. Key Launcher filters out alerts from muted/blacklisted apps to protect your focus.

The Notification Center also features an inline Calendar & Agenda view, displaying upcoming events directly below your active alerts.

newspaper

Discover RSS News Feed

An offline news reader styled like Google Discover. Feeds are aggregate RSS content parsed using a lightweight XML parser.

  • Topic Chips: Filter articles instantly by clicking category chips: All, News, Tech, Entertainment, Politics, Business, Lifestyle, Finance, Sports.
  • WorkManager Refresh: Automatically fetches new articles in the background every 3 hours when connected to network.
  • PRO Soft Gate: Free accounts display up to 30 stories in the feed. Scrolling beyond 30 displays a Pro Upgrade invitation.

5. Focus Mode & Companion

alarm

Desk Clock & Brightness

Launch Focus Mode to enter a landscape desk clock dashboard. The layout silences all incoming social notifications.

Brightness Control: Slide your finger vertically up and down on the left side of the screen to adjust screen brightness manually. Dragging all the way down returns the device to system auto-brightness.

calendar_month

Lunar & Alternative Calendars

Key Launcher is optimized for lunar date tracking:

  • Alternative Dates: Shows Vietnamese/Chinese Lunar calendar dates directly next to solar calendar figures.
  • Holidays: Lunar calendar holidays are displayed directly above the clock banner.
  • Lunar Alarms: Set custom recurring alarms or task entries linked to lunar dates (e.g. traditional festivals).
view_carousel

Dashboard Pager Widgets

Scroll through active widgets on the right side of the Focus dashboard:

  • CALENDAR: Minimalist monthly grid.
  • MUSIC: Vertical media control card with track details and play/pause/skip buttons.
  • TIMER: Interval Pomodoro focus timer with short and long break configs.
  • DINO: Embedded classic offline Dino T-Rex running game.
  • POLAROID: Floating slideshow cycling through custom selected image directories.
screen_rotation

OLED Burn-in Protection

To prevent burn-in when using Focus Mode as an always-on desk clock, a screensaver triggers after a configured idle period:

  • Style 1 (Bouncing Clock): Current time and weather/lyrics bounce off screen boundaries like the classic DVD logo screensaver.
  • Style 2 (Drifting Polaroid): A floating photo frame slides slowly across the screen using fractional delta shifts, ensuring pixels remain active.

6. Utilities & Detox Limits

hourglass_disabled

App Limits & Detox

Set daily usage caps on distracting apps. Once the limit is met, Key Launcher blocks the app from launching for the remainder of the day.

Free plan limits: 1 App Limit slot. Upgrading to PRO unlocks unlimited slots.

restore

Local Backup & Restore

Export launcher layout configurations locally to your device folder. Backup files contain folders list, hotkey mappings, monochrome colors, and edge panels ordering. Import backups on new devices to sync layouts instantly.
